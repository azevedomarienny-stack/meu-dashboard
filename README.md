# WorkStart Dashboard
Dashboard inteligente desenvolvido com HTML, CSS e JavaScript, focado em produtividade e organização do início do dia.

O projeto foi criado com o objetivo de centralizar informações importantes em uma interface moderna, limpa e funcional, permitindo uma visualização rápida de emails, reuniões e alertas prioritários sincronizados com a conta Google do usuário.

# Funcionalidades:
- Login com Google OAuth 2.0
- Integração com Gmail API
- Integração com Google Calendar API
- Contagem de emails não lidos
- Visualização de reuniões do dia
- Alertas prioritários do LinkedIn e Glassdoor
- Gráfico de volume de emails dos últimos 7 dias
- Links rápidos para ferramentas Google
- Interface responsiva e moderna
- Atualização dinâmica de dados em tempo real
## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google APIs
- Google Identity Services
- Chart.js
